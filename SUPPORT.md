# Support

Choose the channel that matches the request:

- Read the [English overview](./README.md) or [中文说明](./README.zh-CN.md).
- Use [GitHub Discussions](https://github.com/context4ai/context/discussions) for usage and integration questions.
- Open a [bug report](https://github.com/context4ai/context/issues/new/choose) for reproducible defects.
- Follow [SECURITY.md](./SECURITY.md) for vulnerabilities.

When asking for help, include the Context version, installation mode, Node.js and Bun versions, the command you ran, and sanitized diagnostic output. Do not publish source documents, review payloads, credentials, private paths, or generated knowledge from a private workspace.
