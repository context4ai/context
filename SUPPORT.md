# Support

Choose the channel that matches the request:

- Start with the [documentation](https://context4ai.org/context/), especially
  the [FAQ](https://context4ai.org/context/pages/eac245c4b0bc8346acc3bd56fa10ea6b.html)
  and [Support](https://context4ai.org/context/pages/53f68cc7830ffd2893f3f8e142ef6bbe.html)
  pages.
- Use [GitHub Discussions](https://github.com/context4ai/context/discussions)
  for usage and integration questions.
- Open a [bug report](https://github.com/context4ai/context/issues/new/choose)
  for reproducible defects.
- Follow [SECURITY.md](./SECURITY.md) for vulnerabilities.

When asking for help, include the Context version (`context --version`), the
installation mode, Node.js and Bun versions, the Agent host, the command or
entry you ran, and sanitized diagnostic output. Do not publish source
documents, review payloads, credentials, private paths or generated knowledge
from a private workspace.
