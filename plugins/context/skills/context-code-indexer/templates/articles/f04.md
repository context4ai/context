# F04 状态与数据流

This is a writing blueprint, not a completion gate. Adapt the headings and level of detail to the reader, evidence and language. Missing or additional chapters and ordinary version differences are advisory. Preserve real source coordinates and a useful next investigation step.

生成条件：跨页面／组件状态、缓存或宿主上下文影响行为。

建议章节：**状态分层 → 核心状态表 → 读写与派生关系 → 请求缓存及刷新 → 持久化与恢复 → 排查入口**。

状态表列：状态身份、来源／owner、作用范围、初始化、主要写入者、使用者、清理／刷新入口。区分本地状态、URL、服务端缓存和宿主注入；不强行要求 Redux、Jotai 或任何特定框架。仅当可证明状态与转移时绘制状态图。

## 图示选择

数据流用带读写标签的 flowchart；stateDiagram-v2 仅用于有触发条件和转移证据的状态。 图放在对应解释章节，图前说明目的与范围，图后给来源和继续位置；按已下发的共用图示指导编写，无增益时省略，不增加独立必填章节。
