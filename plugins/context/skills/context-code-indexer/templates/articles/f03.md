# F03 页面／用户任务详情

This is a writing blueprint, not a completion gate. Adapt the headings and level of detail to the reader, evidence and language. Missing or additional chapters and ordinary version differences are advisory. Preserve real source coordinates and a useful next investigation step.

生成条件：页面或用户任务有独立定位价值；按真实问题、复杂度或维护目标选择，不为每个内部组件生成一篇。

建议章节：**页面定位 → 路由、参数与权限 → 主要组件与依赖 → 页面内流程 → 状态与数据流 → API 边界 → 业务条件 → Loading／Empty／Error → 相关知识与源码**。

按证据增加埋点／监控。每个主要动作记录触发位置、调用入口、结果处理；已读取的禁用／隐藏条件说明对应来源，未读深层逻辑则给出具体继续位置。组件树只保留解释任务需要的节点。

最低产出为“入口、父层访问控制、主要交互处理位置、下一步”，不要求预先证明整条业务闭环。API 参数表使用规范契约产物，页面只解释绑定和使用差异。

## 图示选择

页面行为用 flowchart TD；跨组件请求时序有证据再用 sequenceDiagram，保留父层条件和失败出口。 图放在对应解释章节，图前说明目的与范围，图后给来源和继续位置；按已下发的共用图示指导编写，无增益时省略，不增加独立必填章节。
