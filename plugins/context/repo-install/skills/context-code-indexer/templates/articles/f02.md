# F02 路由与页面地图

This is a writing blueprint, not a completion gate. Adapt the headings and level of detail to the reader, evidence and language. Missing or additional chapters and ordinary version differences are advisory. Preserve real source coordinates and a useful next investigation step.

生成条件：已定位显式路由表、文件路由规则或页面注册机制。

建议章节：**路由组织 → 页面登记表 → 参数与访问控制 → 布局和全局兜底 → 页面详情导航**。

登记表列：业务页面名、完整／相对路由及 base、入口文件、layout／guard、主要数据边界、详情或源码链接。声明 route、导航可达与运行权限分别说明；没有本地 guard 不能推出没有权限控制。生成路由必须指出规则来源和消费点。

最小入口不要求解释所有按钮；至少让 Agent 从页面找到入口及父层条件。目录名本身不能充当页面登记证据。

## 图示选择

路由优先表格，layout/guard 层级可用 text 树或 flowchart；注册不代表运行可达。 图放在对应解释章节，图前说明目的与范围，图后给来源和继续位置；按已下发的共用图示指导编写，无增益时省略，不增加独立必填章节。
